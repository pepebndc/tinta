# Tinta launch video

This folder contains everything that makes the Tinta launch video: the animation, the soundtrack, and the renderer. One build makes two cuts:

| File | Size | Use |
|---|---|---|
| `tinta-launch.mp4` | 1920 × 1080, 60 fps, 38 s | X, LinkedIn, the website |
| `tinta-launch-vertical.mp4` | 1080 × 1920, 60 fps, 38 s | TikTok, Reels, Shorts |

Both files use H.264 video and AAC audio at −14 LUFS.

## Requirements

- macOS with Google Chrome in `/Applications`. The animation uses the macOS system font (SF) and Brush Script MT for the wordmark. To use a different Chrome, set `CHROME` to the path of its executable.
- Node.js 20 or later.
- ffmpeg.
- Python 3, only for contact sheets.

## Build

```sh
cd marketing/launch-video
./build.sh              # soundtrack, landscape cut, and vertical cut
./build.sh landscape    # soundtrack and landscape cut only
./build.sh vertical     # soundtrack and vertical cut only
```

The first run installs the dependencies with `npm ci`. Each cut takes approximately 5 to 7 minutes on an Apple Silicon Mac. To change the number of parallel Chrome workers, set `WORKERS` (the default is 4).

The build writes these files in this folder. Git ignores them.

- `music.wav`: the soundtrack.
- `video.mp4` and `video-vertical.mp4`: the picture masters, without audio.
- `tinta-launch.mp4` and `tinta-launch-vertical.mp4`: the final files with audio.

## Check frames before a full render

A full render is slow. To check a change, render stills at specific times, in seconds:

```sh
node render.mjs stills 4.2 13.8 30.4           # landscape, writes stills/t<time>.jpg
VERT=1 node render.mjs stills 4.2 13.8 30.4    # vertical, writes stills/v<time>.jpg
python3 sheet.py t                              # contact sheet of the landscape stills (c1.jpg, ...)
python3 sheet.py v                              # contact sheet of the vertical stills
```

To see one frame in a browser, open `index.html?t=13.8`. Add `&v` for the vertical layout.

## Files

| File | Contents |
|---|---|
| `timeline.js` | All the timings, in seconds. The animation and the soundtrack both read this file, so a change here moves the picture and the sound together. |
| `index.html` | The scenes, the copy, the recreated app UI, and the motion. `render(t)` draws the frame at time `t`. Each frame depends only on `t`, so any frame can render in any order. |
| `music.mjs` | The score and the sound design, at 120 BPM. One bar is 2 s. It writes `music.wav`. |
| `render.mjs` | Renders stills or a full cut in Chrome with Puppeteer. |
| `build.sh` | Runs the full build and adds the soundtrack to each cut. |
| `sheet.py` | Makes contact sheets from stills. |
| `fonts/` | Instrument Serif, for the italic accent words. |

## How the video works

- **Timeline.** The film has seven scenes: the hook, the logo, the app, the summary, privacy, MCP, and the end card. `timeline.js` sets the start time of each scene and each event. For example, the cursor click, the speaker name change, and the lock click.
- **Motion blur.** `render.mjs` renders 4 samples for each frame across a 180 degree shutter, and ffmpeg averages them. Fast moves stay smooth.
- **Grain.** The master gets fine film grain, which also prevents banding in the gradients.
- **Parallel render.** Each worker renders one part of the film. Then ffmpeg joins the parts.
- **Vertical cut.** `VERT=1` (or `?v` in the URL) turns on the vertical layout in `index.html`. The vertical cut uses the same timeline and soundtrack, with its own layout and camera moves. All key content stays between y 230 and y 1560, so the TikTok controls do not cover it.

## Keep the video in line with the app

The video recreates the brand and the app UI in HTML. When the app changes, update `index.html` to match:

- **Colors.** The `:root` variables in `index.html` use the values from `app/src/styles.css`.
- **Mark.** The two paths of the mark are the same as `InkMark` in `app/src/Brand.tsx`.
- **Wordmark.** The wordmark uses the `.wordmark` style from `app/src/styles.css`: Brush Script MT, `letter-spacing: 0.01em`, and `rotate(-2deg)`.
- **Lockup.** The lockup uses the proportions of `Lockup` in `app/src/Brand.tsx`: a 30 px mark, a 44 px wordmark, and a 12 px gap. The large lockups use these proportions at 7.5 times the size, so the logo lands exactly on the app sidebar logo.
- **App screens.** The app screens follow `docs/images/home.png` and `docs/images/recording.png`.
